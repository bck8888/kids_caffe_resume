# 서울 키즈카페 찾기

서울형 키즈카페의 시설 위치와 날짜별 회차·잔여석을 확인하고 서울시 공식 예약 페이지로 이동하는 모바일 웹 MVP입니다.

## MVP 기능

- 서울형 키즈카페 시설 목록 조회
- 시설명·자치구·주소 검색
- 카카오맵 시설 위치 표시
- 날짜별 회차·잔여석·대기·취소기한 조회
- 서울시 공식 예약 페이지 연결
- 카카오톡 시설 공유
- 예약 일정 브라우저 저장 및 삭제

## 데이터 출처

- 서울 열린데이터광장 `서울형 키즈카페 시설현황정보`
- 우리동네키움포털 공개 예약 회차 응답
- 서울시 공식 예약 페이지

시설 기본정보는 공공누리 제1유형에 따라 출처를 표시해 사용합니다. 우리동네키움포털 회차 응답은 공식 Open API가 아니므로 공개 서비스 운영 전 사용 허용 범위 확인이 필요합니다.

## 실행

```bash
npm install
cp .env.example .env.local
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 환경변수

```text
SEOUL_OPEN_API_KEY=
SEOUL_RESERVATION_API_KEY=
NEXT_PUBLIC_KAKAO_JAVASCRIPT_KEY=
KAKAO_REST_API_KEY=
```

실제 키는 `.env.local`에서만 관리하며 Git에 포함하지 않습니다.

## 점검

```bash
npm run check
npm run build
```

## 현재 제한

- 서울시 로그인·예약 신청·취소를 앱이 대행하지 않습니다.
- 예약 완료 여부는 자동으로 확인하지 않으며 사용자가 일정을 직접 저장합니다.
- 카카오톡 공유 링크의 운영 도메인은 실제 배포 URL 확정 후 추가 등록해야 합니다.
- 외부 예약시스템을 사용하는 일부 시설은 후속 매핑이 필요합니다.
- 우리동네키움포털 비공식 공개 응답의 정책 또는 구조가 변경되면 연동 수정이 필요합니다.
